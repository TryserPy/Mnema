# Контекст проекта «Мнема» — что важно помнить

> Этот файл ведёт агент **context-keeper**. Все агенты читают его первым делом.
> Здесь только главное: кто автор и чего он хочет, принятые решения, текущее состояние, открытые просьбы.
> Подробное описание продукта и кода — `docs/PROJECT.md`, правила работы — `CLAUDE.md`.

## Автор и как с ним работать
- Автор — ученик, пишет по-русски, часто голосом (бывают опечатки). Сам тестирует на Windows и Android и присылает скриншоты.
- Отвечать по-русски, коротко: что сделано, как пользоваться, что не проверено, 3–5 идей.
- Продукт для других людей: простые слова, понятно ребёнку, одна главная кнопка, редкое — в «⋯», новое — за переключателем в «Возможностях».
- Не любит: вылезающий текст, меню за краем, длинные страницы, серые полосы прокрутки, тормоза, «табличку» из кнопок там, где была строка.
- Любит: функции на основе исследований о памяти, когда Claude добавляет что-то от себя, идеи в конце.
- Честно говорить, что не проверено на настоящем телефоне.

## Команда агентов (`.claude/agents/`)
Главный — Claude в чате (раздаёт задачи и собирает результат). Агенты независимы: **не читают отчёты друг друга**,
опираются только на код, требования и этот файл.
- `context-keeper` — ведёт этот файл; к нему обращаются за контекстом.
- `security-reviewer` — безопасность.
- `test-runner` — код и модульные тесты (логика, совместимость данных).
- `design-reviewer` — визуал на компьютере и телефоне, тексты интерфейса.
- `verifier` — независимо перепроверяет и тесты, и визуал; выносит вердикт по каждому требованию.
- `idea-generator` — идеи на основе приложения, исследований и этого контекста.
- `builder` — собирает: веб-сборку, APK, установщик Windows (через GitHub Actions), проверяет файлы.
- `publisher` — GitHub: pull request в main, выпуск, оформление README/CHANGELOG и страницы выпуска.
- `desktop-engineer` — версия для Windows (Electron).
- `android-engineer` — версия для телефона (Android-обёртка).

## Как выходит новая версия (решено в 1.7.0)
- Репозиторий `TryserPy/Mnema` публичный, основная ветка `main`. Claude работает в ветке `claude/…` и может пушить только в неё
  (метки `v*` и `main` отсюда не пушатся).
- Выпуск: pull request ветки → `main`, после зелёных проверок — влить, затем запустить workflow «Выпуск» (`release.yml`,
  workflow_dispatch на `main`). Он сам ставит метку `vX.Y.Z` и публикует APK, `Mnema-Setup-X.Y.Z.exe`, `.blockmap`, `latest.yml`.
- Ключ подписи APK — только в секрете `ANDROID_KEYSTORE_B64`. Сертификат SHA-256 `37c7f1fb…ebf64` — один на все версии.
- Приложение само берёт обновления из выпусков `TryserPy/Mnema` (зашито в код, не в настройки).

## Принятые решения (не ломать)
- Переключатели (Segmented) на компьютере — всегда в одну строку. На телефоне 4+ пунктов — 2+2, только если не помещаются.
- На телефоне нет подсказок про клавиши и мышь; панель выделения сама не выскакивает (на Android — пункты в родном меню выделения).
- Мост `MnemaAndroid` принимает вызовы только с ключом главной страницы.
- Файл изменений: основной формат — «Мнема-текст» (`src/mnemaText.ts`, строки `@предмет`, `@тема`, `@карточки`…), JSON тоже принимается.
  Нейросеть не ставит «важная» и ничего не удаляет без просьбы. Перед применением — наглядный предпросмотр, после — «Вернуть».
- Значок на Android — activity-alias; главный ярлык сохраняет имя `MainActivity`, окно — `AppActivity`.
- Темы по умолчанию стоят по названию (`Intl.Collator` ru, numeric: 1, 2, 10). Перетащил тему между соседями — порядок сам
  становится «своим»; в «⋯» предмета можно переключить обратно.
- Таблицы в конспекте хранятся как Markdown (`| a | b |`) — так их понимают Obsidian и нейросеть.
- Панель выделения: строка оформления с подписями + список действий; «В карточку» — цветная строка с пояснением.
- Выбор нескольких (папки/предметы/темы): Ctrl/Shift+щелчок или «Выбрать несколько» в меню; удаление — через окно со списком и «Вернуть».
- Свой фон — `settings.bgImage` (JPEG до 1920 px) под полупрозрачным цветом темы, ползунок видимости, «Убрать».
- Значок телефона — `settings.appIcon`: `'default'` | `'theme'` | id темы (17 вариантов, независимо от темы).
