## Как продолжить
1. Получить ветки: `git fetch origin`.
2. Для каждой области поднять кодера Sonnet. Задание дать по этому файлу и по заметке в `docs/handoff/<область>.md`.
3. Когда всё готово, руководитель:
   - вливает запасные ветки в `claude/nice-cerf-hsheob` и удаляет их;
   - поднимает версию 1.29.0 (`package.json`, `CHANGELOG.md`, «что нового» в Settings и на сайте в `js/data.js`);
   - делает полную проверку и проверку безопасности: tsc, vitest, `build:web`, санитизация CSS/Markdown/картинок, zip-slip, миграция папки данных без потери данных.
4. Haiku: PR в main, CI, слияние. Пользователь проверяет онлайн-версию.

## Решения, о которых знает пользователь
- **Домашка.** Сделанная исчезает на следующий учебный день. При первом запуске 1.29 удалится старое «Сделано».
- **Копирование.** У копии предмета или темы расписание повторений начинается с нуля.
- **Онлайн-версия.** Только для тестов, предупреждение показывается при каждом заходе.
- **Проверка Cloudflare «Workers Builds: mnema-ai-test»** падает. Она внешняя, к CI репозитория не относится и не разбиралась.
