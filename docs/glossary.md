# Словарь Refrain

Одни и те же вещи называются одинаково везде: на экранах, в меню, в подсказках, в «Помощи», в «Что нового»
и на сайте (репозиторий Mnema-site). Короткая версия для учеников — `src/glossary.ts` («Помощь → Словарь»).

Правило: пишем так, как сказал бы школьник. Если слово требует объяснения — рядом короткая подпись (одна строка,
максимум две), а не ссылка на инструкцию.

## Что как называется

| Пишем | Что это | Не пишем |
| --- | --- | --- |
| **Предмет** | «Геометрия», «Биология». В нём — темы. | дисциплина, курс, колода |
| **Папка** | Несколько предметов вместе. | группа, категория |
| **Тема** | Один параграф или раздел учебника: конспект + карточки. | урок, глава (в интерфейсе), карточка темы |
| **Подтема** | Тема внутри темы. Путь: «Геометрия › Четырёхугольники › Параллелограмм». | дочерняя тема, вложенная тема |
| **Конспект** | Текст темы своими словами. | заметка, записи, note |
| **Новый конспект** | Пункт «Создать»: новая тема, сразу на вкладке конспекта. | новая заметка |
| **Карточка** | Вопрос и ответ. | флешкарта, флеш-карта, card |
| **Термин** | Строка таблицы «слово — значение» (вкладка «Термины», списки: словарь, даты, формулы). | понятие (как название вкладки), запись |
| **Правило** | Правило предмета; его слова подсвечиваются в конспектах. | правило-подсказка |
| **Учиться** / **Учить** | Главная кнопка: что пора повторить. «Учиться» — везде, «Учить · 3» — у темы. | тренироваться, заниматься, начать сессию |
| **Повторить ещё раз** | Сверх плана, без изменения расписания. | зубрёжка, крам, cram |
| **Что учить** | Всё / только карточки / только термины. | фильтр, режим |
| **Расписание повторений** | Когда карточка придёт снова (FSRS). | интервалы, алгоритм, FSRS (в интерфейсе) |
| **Контрольная** | Дата и темы; по ним — план повторений. | экзамен, тест (в значении «контрольная») |
| **Пробная контрольная** | Проверка себя без изменения расписания. | тест, квиз |
| **Выучено N%** | Доля карточек темы, которые ты помнишь уверенно (полоска у темы). | прогресс, освоение (в подписи у темы) |
| **N сегодня** | Сколько карточек темы повторить сегодня (число у темы). | голое число в кружке без подписи |
| **Учить всё на сегодня: N карточек** | Кнопка «▶ N» в шапке телефона. | — |
| **Экспорт в Anki** | Файл .apkg с прогрессом. | выгрузка в Anki |
| **Выгрузить для нейросети** | Файл, который нейросеть поправит и вернёт «файлом изменений». | экспорт для ИИ |
| **Файл изменений** | Ответ нейросети, который Refrain применяет к предметам и темам. | патч, diff |
| **Корзина** | Удалённое за 30 дней, можно вернуть. | архив |
| **Масштаб** | Всё крупнее или мельче (текст, кнопки, значки) — только на этом устройстве. | зум |
| **Размер текста** | Только буквы. | шрифт (в значении размера) |
| **Сохранено** / **Сохраняется…** / **Нет сети — сохранено на устройстве** | Состояние конспекта. | синхронизировано (если не было синхронизации) |
| **Чтение** / **Правка** | Режим конспекта: в чтении текст не меняется. | просмотр/редактирование |
| **Учусь · Знания · Профиль** | Нижняя панель телефона. | Главная, Библиотека, Аккаунт |

## Меню «⋮» предмета и темы

Пункты сгруппированы, заголовки групп — одни и те же:

- **Учить** — учить весь предмет · что учить · повторить ещё раз (у темы — ещё «Проверить себя»);
- **Карточки** (только у темы) — карточки из конспекта, черновики от ИИ, из ссылки, решить задачу, из учебника;
- **Подготовка** — новая контрольная (у темы — «Назначить контрольную»);
- **Управление** — название и цвет, сделать копию, порядок тем, подтема, история конспекта;
- **Экспорт** — распечатать, Экспорт в Anki, выгрузить для нейросети, поделиться файлом;
- опасное («Удалить…») — последним, за чертой, красным.

Подсказка под пунктом — что произойдёт, а не как это устроено: «15 карточек на сегодня», «Без изменения расписания»,
«Выбери темы и дату — будет план».

## Опасные действия

- **Удалить** — окно подтверждения, после удаления — тост «Вернуть»; удалённое 30 дней лежит в «Корзине».
- **Сделать копию** — сразу, без вопроса, с тостом «Открыть» и «Отменить» (копия исчезает совсем, без корзины).
- **Удалить всё** (настройки → данные) — только с подтверждением. Отдельной кнопки «Сбросить прогресс» в Refrain нет.

## Числа и подписи

- Число без слова не оставляем: «3 сегодня», «15 карточек», «выучено 40%», «Учить · 3».
- Склонение — через `plural()`: «1 карточка», «3 карточки», «5 карточек».
- Кнопка-значок всегда с `aria-label` словами (для TalkBack и VoiceOver) и с `title` на компьютере.
