## 3. Разметка и переносимость

### Аудит: что сейчас попадает в .md конспекта и как это видят другие программы

Хранение: Markdown из TipTap (`@tiptap/markdown`), показ — `marked` + расширения (`src/components/Markdown.tsx`) и DOMPurify.

| Конструкция | Как хранится | Obsidian | Typora | VS Code / GitHub | Logseq | Notion (импорт) |
|---|---|---|---|---|---|---|
| Заголовки, жирный, курсив, зачёркнутый, код, списки, цитаты | CommonMark | да | да | да | да | да |
| Таблицы (`PipeSafeTable`, `\|` в ячейках экранируется) | GFM | да | да | да | да | да |
| Формулы `$…$` и блок `$$\nTeX\n$$` | как в Obsidian/Typora | да | да | да (GitHub), VS Code — со встроенным KaTeX | `$…$` да | частично (нужна ручная правка) |
| Выделение `==текст==` | расширение Obsidian | да | да (включить в настройках) | нет (видно `==`) | нет | нет |
| Подчёркивание `++текст++` (TipTap Underline) | нестандартно | нет | нет | нет | нет | нет — при экспорте заменить на `<u>…</u>` (кнопки подчёркивания в интерфейсе нет, проверить) |
| Рисунок: `![Рисунок](data:image/svg+xml…)` прямо в тексте (в SVG точки штрихов в `data-points`) | data URI | показывает, но файл раздут | да | GitHub не показывает data URI в SVG, часто режет | нет | нет |
| Фото/картинки: `![alt](data:image/png;base64,…)` | data URI внутри текста | показывает, файл раздут | да | VS Code да, GitHub — большие не открываются | нет | нет |
| Видео: `![video](https://youtube/…)` | картинка-ссылка | встраивает плеер | нет (битая картинка) | GitHub — битая картинка | нет | нет |
| Ссылки между темами: `[текст](mnema://topic/<id>)`, `[текст](mnema://card/<id>)` | своя схема | не открывает | не открывает | не открывает | нет | нет |
| Номера страниц учебника `\[стр. 12\]` | экранированный текст | видно как `[стр. 12]` | так же | так же | так же | так же |
| «Рамки» учебника `> **Запомните:** текст` | обычная цитата с жирным | цитата | цитата | цитата | цитата | цитата (callout'ов нет) |
| Callout'ов Obsidian `> [!note]` в хранении нет; при импорте из Obsidian превращаются в `> **Заголовок**` | — | — | — | — | — | — |
| Формулы/слова в карточках: `{{c1::пропуск::подсказка}}`, задачи `{U=10..220}`/`{=U/R}`, ответ ввода `а\|б` | свои поля, не в .md | — | — | — | — | — |
| Карточки в `.md` | в хранении нет (отдельный список) | в экспорте для Obsidian — `Вопрос::Ответ` под `#flashcards` (плагин Spaced Repetition) | — | — | — | — |
| Метаданные темы | нет frontmatter в хранении; в экспорте для Obsidian — `мнема-id`, `предмет`, `контрольная`, `tags` | да | да | GitHub показывает таблицу | свойства | нет |

Итог: ядро (CommonMark + GFM + `$…$` + `==…==`) переносимо; непереносимо — data URI, `mnema://`-ссылки, видео как картинка, `++`, номера страниц.
