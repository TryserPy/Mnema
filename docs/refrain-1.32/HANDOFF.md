## Что требует действий владельца

1. Слить ветку `claude/fervent-carson-8fgccx` (PR — когда скажешь). Веб-версия выложится на сайт сама (`web.yml`), правок в Mnema-site не нужно.
2. **Сервер — до выпуска приложения.** `cd server && npx wrangler d1 migrations apply refrain --remote && npx wrangler deploy` (или Actions →
   «Сервер Refrain ИИ» → deploy). Новых миграций в этой части нет (0002 — из первой части; `/v1/extract` пишет в существующую таблицу `counters`).
   ⚠️ Если выпустить приложение 1.32 раньше сервера, старый сервер ответит на задачи `cards.source` и `solve` «неизвестная задача», а детектор
   начислит баллы (`unknown_task`, вес 25). Порядок: сервер → тег выпуска. Затем `node scripts/set-webhook.mjs` (кнопки бота).
3. **Яндекс Диск**: зарегистрировать приложение на https://oauth.yandex.ru → «Создать приложение» → платформа «Веб-сервисы»,
   Redirect URI: `https://oauth.yandex.ru/verification_code`; доступ: «Яндекс.Диск REST API → Доступ к папке приложения на Диске»
   (`cloud_api:disk.app_folder`). ClientID (32 символа, не секрет) — в переменную репозитория `YANDEX_CLIENT_ID`
   (Settings → Secrets and variables → Actions → Variables). Секрет приложения не нужен.
4. Проверить на настоящем телефоне: вход по почте, Яндекс Диск, жесты холста, уведомление помодоро, Telegram-кнопки; из этой части —
   свайпы и «потяни вниз» (вибрация), съёмка задачи камерой, рамки пальцем и стилусом, YouTube и статьи по ссылке с настоящего сервера,
   экспорт «Закрыть часть картинки» в настоящую Anki (23.10+ и AnkiDroid).
