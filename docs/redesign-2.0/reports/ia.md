## 1. Короткий итог (что предлагаю)

1. **Три места: Учусь · Знания · Профиль — идея верна**, и в коде она уже почти есть (сверху «Сегодня/Домашка», посередине дерево предметов, внизу значки Статистика/Настройки/Справка), но без подписей и с дырами. Правлю её в четырёх местах:
   - «Повторение», «Тесты», «Автопилот», «Умный план» — **не пункты меню**, а действия. Это одна кнопка «Учиться» и шаги плана. **«Умный план» и «Автопилот» — одна функция** (у автора они записаны дважды): строить порядок один раз, показывать его списком шагов, «Начать план» = «Учиться».
   - «Статистика» режем на две половины: **«что я знаю»** (слабые места, карта) → Знания; **«что я делал»** (дни, минуты, итоги недели) → Профиль → «Мой прогресс». Сейчас в «Статистике» 4 вкладки, и 3 из них — не статистика (достижения, сад, карта).
   - «Профиль» в приложении без аккаунта — слово без содержания (нет имени, фото). Оставляю название только если лицо раздела — «Мой прогресс» (сводка из 3 цифр), а под ней настройки, возможности, корзина, справка. Иначе честнее «Ещё». Решение за автором (вопрос Q3).
   - «История» — две разные вещи: история **конспекта** (версии) живёт внутри темы, в «⋯»; **корзина** — в Профиле. «История занятий» = «Мой прогресс».
2. **Телефон:** нижняя панель из 4 мест `Учусь · Знания · ＋ · Профиль`; шторка ☰ уходит. **Компьютер:** панель слева с тремя подписанными группами, дерево предметов всегда видно.
3. **Глобальное «＋»:** один реестр действий, зависящий от места; локальные «＋» либо вызывают те же действия, либо исчезают (в строках дерева, у вкладок темы, на карточке «Домашка»).
4. **Переключатели «Возможностей»: 21 → 13.** Уходят: `leeches`, `test`, `focus`, `tips`, `weekly` (становятся частью ядра), `awards`, `garden`, `mods` (удаляются).
5. **Удаляется:** моды с кодом, «Стили» как отдельный раздел (3 полезных пресета уходят в «Оформление»), справка «Формулы» (редактор формул остаётся), «Сад», «Достижения», «Совет дня», серия-плашка, поздравления.
6. **Все экраны подчиняются единому каркасу** (раздел 8): шапка, одна главная кнопка, «⋯» не длиннее 8 строк, назад по иерархии, вкладки ≤3 на телефоне, единое пустое состояние, меню на телефоне — всегда нижние шторки.
7. **Находки, которые меняют постановку задач:**
   - Баг 3 (период): по коду блоки «итоги недели», «16 недель» и «прогноз» **уже не зависят от периода** (`Stats.tsx:157-163` — зависят только KPI и «Слабые темы»; `:167` тепловая карта берёт `data.logs`, `:195` прогноз без периода, `WeekCard` со своим переключателем). Ошибка в раскладке: переключатель стоит в шапке над всем (`:244-255`). Значит, чинить надо группировкой блоков, а не вычислениями.
   - Правило автора «выключенная функция нигде не видна» нарушено минимум в 5 местах (раздел 3, П-8).
   - «Контрольные» — не раздел, а атрибут темы (`Topic.examDate`); общего списка нет, на «Сегодня» видны 3 ближайшие (`Today.tsx:35`).

## 3. Проблемы текущей структуры

**П-1. Дубли входов.**
- «Правила»: 5 входов — строка в дереве (`Sidebar.tsx:327`), пункт меню предмета (`:597`), вкладка предмета (`SubjectScreen.tsx:116`), кнопка в теме (`TopicScreen.tsx:275`), группа в поиске (`CommandPalette.tsx:126`).
- «Возможности»: значок (`Sidebar.tsx:429`) + раздел настроек (`Settings.tsx:86`) + команда поиска (`CommandPalette.tsx:86`) + отдельный Route `features` с особой подсветкой (`Sidebar.tsx:429,454`).
- «Клавиши»: один и тот же `KeySettings` в «Настройки → Клавиши» (`Settings.tsx:185`) и «Справка → Клавиши» (`Help.tsx:127`).
- Значок у часов (`tray`): переключатель в «Возможностях» и второй — в «Напоминаниях» (`Settings.tsx:377`).
- Две команды поиска про домашку; обе просто открывают экран, «Записать» ничего не записывает (`CommandPalette.tsx:76`).
- Экспорт/печать/Anki: Настройки → Данные (`Settings.tsx:488-506`), меню предмета (`SubjectScreen.tsx:76,80`), меню темы (`TopicScreen.tsx:177`).
- Файл изменений: Настройки → Данные, 2 команды поиска, пункты «Выгрузить для нейросети» в меню предмета и темы, перетаскивание файла.
- Одна булева «важная тема» — пять управляющих элементов: ★ в дереве (`Sidebar.tsx:252`), ★ в шапке (`TopicScreen.tsx:111`), пункт «⋯» темы (`:170`), пункт контекстного меню (`Sidebar.tsx:658`), Ctrl+D; смотреть список «всех важных» негде, на «Сегодня» только первые 6 в порядке данных (`Today.tsx:43`).
- «Важное» (панель найденного в конспекте) и «Важные темы» (звезда) — **одно слово для двух разных вещей**.
- «Тема» в настройках («Оформление → Тема», `LookSettings.tsx:74`) и «тема» урока.
- Для «проверить себя» три формулировки: «Проверь себя до чтения», «Пробная контрольная», «Проверить себя» (`TopicScreen.tsx:172-173`, `Today.tsx:183`). Для «учить» — «Начать», «Учить · N», «Готовиться · N», «Подготовиться к завтра», «Разминка», «Повторить всю тему».

**П-2. Потерянные и «сироты».**
- Карта, Сад, Достижения лежат вкладками внутри «Статистики» (`Stats.tsx:199-204`), хотя не статистика.
- «Слабые темы» — только карточка в «Статистике» (`Stats.tsx:180-193`), с процентом верных за период. Это единственное место, где про них вообще говорится, и из него нет действия («Исправить»).
- «Контрольные»: нет списка, нет создания «предмет + дата», нет темы-нескольких; дата — поле в шапке темы (`TopicScreen.tsx:127-157`).
- «Закрой и перескажи», «Проверь себя до чтения», «Пробная контрольная» — суть продукта (самопроверка, предтест) — спрятаны в «⋯» темы (`TopicScreen.tsx:164-181`).
- Нет корзины и истории: единственное «вернуть» — тост на 3,5–8 с (`App.tsx:398`); `deleted` в данных — только отметки для синхронизации без содержимого (`store.ts:333`).
- Расписание уроков: карточка на «Сегодня» + модальное окно, отдельной страницы нет.
- Стихи: нет места, кроме вкладки темы; в поиске их нет (`CommandPalette.tsx` — группы Предметы/Темы/Правила/Карточки/Домашка).

**П-3. Глубокие места.**
- Дерево предметов без ограничения глубины: Папка › Предмет › Тема › Подтема › … Отступ 16 px на уровень в панели (`Sidebar.tsx:225`) и 28 px в списке тем (`SubjectScreen.tsx:149`) — на узком экране глубже 3-го уровня не остаётся места под название (оценка по коду, не измерено).
- Телефон: любая цель — минимум 2 касания через ☰, и **значки подвала без подписей** (скриншот `m390-drawer.png`: 4 безымянных значка; подсказок-«title» на касании нет). «Возможности» — значок-сетка, смысл которой не угадать.
- Настройки: 4 места про внешний вид (Оформление, Текст и форма, Анимации, Стили) + Возможности внутри настроек + «О Мнеме» с 8 списками «Новое в 1.5…1.8» (`Settings.tsx:621-698`) — длинная прокручиваемая страница.
- Статистика: два переключателя на одном уровне (период + вкладки), и период выглядит главным для всего.
- Две несовпадающие границы «телефона»: `useMobile` — ширина ≤ 720 (`App.tsx:35`), `touchUI()` — указатель coarse или Android (`ui.tsx:813`). Планшет получает панель слева, но «касательные» подсказки; узкое окно компьютера — шторку, но подсказки про мышь.

**П-4. Две «обёртки одного и того же» в списке автора.** «Умный план» и «Учебный автопилот» = один «Учиться». «Подготовка к контрольной» и «Работа над ошибками» = виды шагов плана и кнопка «Исправить» у слабого места. «Быстрый вопрос» в «+» и «Карточка» — одно и то же, если «быстрый вопрос» = вопрос–ответ в одну строку (Q4).

**П-5. «Профиль» без профиля.** Нет имени, аватара, аккаунта. Если внутри только настройки — это «Настройки» или «Ещё».

**П-6. Режимы «Фокус» и «Автопилот».** Фокус-режим (25 + 5 мин, `Today.tsx:118`) — таймерная версия «занятия по времени». Автопилот «10 минут слабая тема…» — то же. Оставлять оба — дубль.

**П-7. Справка смешана с обучением и документацией.** «Как учиться» — первая вкладка Справки (`Help.tsx:20`), там же 15 «полезных кнопок», синхронизация, формулы, API модов.

**П-8. Нарушения «выключенная функция нигде не видна» (проверено):**
- реклама расписания на «Сегодня» при выключенном `schedule` (`Today.tsx:226-230`);
- кнопки «Включить» для домашки и расписания в «Напоминаниях» (`Settings.tsx:343,359`);
- в «Справке» вкладка «Моды» и «Формулы» видны всегда, хотя `mods` выключен по умолчанию (на телефоне получено в браузере: `["Как учиться","Формулы","Моды"]`);
- карточка «Ошибки «с уверенностью»: 0 из 0» в «Статистике» при выключенной `confidence` (виден на скриншоте `d1280-stats.png`, `Stats.tsx:281-285`);
- справка рассказывает про сад и достижения независимо от флагов (`Help.tsx:61`);
- подсказка поиска «…или «>» для команд» показывается и на телефоне (`CommandPalette.tsx:166`; сам `kbd Esc/Enter` на касании скрыт — проверено).

**П-9. Данные выключенных функций ведут себя по-разному:** выключил «Правила» — правила и подсказки пропали; выключил «Стихи» — вкладки со стихами остались. Нужно одно правило (раздел 7).

## 4. Идея автора «Учусь → Знания → Профиль»: разбор

| Что в идее | Оценка | Что делаю |
|---|---|---|
| Три места | Верно и совпадает с существующей раскладкой панели. Три — предел для телефона (3–5 пунктов нижней панели). | Принимаю как основу. |
| Учусь: умный план, повторение, домашка, контрольные, тесты, автопилот | «Повторение», «тесты», «автопилот», «план» — **глаголы**, а не места. Места: список дел со сроком (домашка, контрольные). | Учусь = страница **«Учусь»** (кнопка «Учиться» + «Скоро») и два списка: Домашка, Контрольные. Тесты — действие «Проверить себя» на теме/контрольной. |
| Знания: конспекты, карточки, темы, термины, карты, статистика | Верно кроме «статистики»: в ней смешаны качество знания и активность. Конспекты/карточки — не отдельные экраны, а вкладки темы. | Знания = предметы → темы → (конспект, карточки, списки, стихи) + представления «Слабые места», «Карта». Активность — в Профиль. |
| Профиль: настройки, история, параметры, доп. возможности | «Настройки» и «параметры» — одно и то же. «История» двусмысленна. «Доп. возможности» = «Возможности». | Профиль = Мой прогресс · Настройки (6 разделов) · Возможности · Корзина · Справка · О Мнеме. |
| Порядок слева направо | Совпадает с частотой использования: Учусь (ежедневно) → Знания → Профиль (редко). | Сохраняю. |

**Что я не принимаю механически:**
1. Не делаю «Повторение» и «Тесты» пунктами навигации (категориальная ошибка «глагол рядом с существительным»).
2. Не кладу «Статистику» целиком в «Знания».
3. Не делаю отдельного раздела «Тесты», «ОГЭ», «ЕГЭ»: это шаблоны «Контрольной» (горизонт, число тем), в навигации их нет.
4. «Профиль» — только при условии «лица» из «Мой прогресс» (иначе «Ещё»).

## 5. Итоговая структура

### 5.1 Принципы

1. **У каждой сущности один дом**; в других местах — только представления (счётчик, ссылка, фильтр).
2. **Три места + «＋».** Новое место первого уровня можно добавить, только убрав другое.
3. **Действие ≠ место.** «Учить», «Проверить себя», «Исправить» — кнопки на объекте и шаги плана.
4. **Главное сразу, продвинутое глубже** (уровни T1–T5 в 5.5).
5. **Одинаковая структура на телефоне и компьютере**; отличается только оболочка (панель слева / нижняя панель).

- Каждая вкладка запоминает свой стек: вернулся на «Знания» — открыта та же тема, где остановился (сейчас «назад» на Android всегда ведёт на «Сегодня», `App.tsx:329`).

## 6. Глобальное «＋»

### 6.1 Как устроено

- **Один реестр** `createActions(контекст)`: `{id, подпись, значок, когда(контекст), флаг?, выполнить(контекст)}`. Меню «＋», строка поиска («Создать: …»), пустые состояния и локальные кнопки берут действия из него: одни и те же подписи, одни и те же окна.
- **Контекст** = место + выбранный объект + вкладка + наличие выделения в конспекте.
- **Первая строка — действие по умолчанию** (на компьютере Enter, Ctrl+N открывает меню с выбранной первой строкой). Максимум 7 строк, группы через линию.
- **Телефон:** нижняя шторка, крупные строки, без подсказок про клавиши. **Компьютер:** выпадающее меню у кнопки; справа серые клавиши (`menu-key`, как уже в «Вставить»).
- **Без «＋» (скрыто):** повторение, тест, тренировка стиха, «на весь экран», открытое окно.
- Если у действия нужен объект, которого нет в контексте («Карточка» из «Профиля»), открывается компактный выбор темы (поиск + 3 последние), по умолчанию — последняя открытая тема.

### 6.2 Набор действий по контексту

| Где я | По умолчанию (1-я строка) | Дальше |
|---|---|---|
| Учусь | Домашнее задание | Контрольная · Карточка · Тема · Предмет |
| Домашка | Задание (фокус в строку ввода на экране) | Контрольная · Карточка |
| Контрольные | Контрольная | Домашнее задание |
| Знания (корень) | Предмет | Папка · Тема (спросит предмет) · Карточка (спросит тему) |
| Папка | Предмет в папке | Тема (спросит предмет) |
| Предмет «S» | Тема в «S» | Термин (общий) · Правило в «S»* · Домашка по «S» · Контрольная по «S» · Карточка (спросит тему) |
| Тема «T», вкладка «Конспект» | Карточка в «T» (при выделении — «Карточка из выделенного») | Подтема · Фото учебника → в конспект · Термин · «Ещё в тему ›» · Домашка по «T» · Контрольная по «T» |
| Тема «T», вкладка «Карточки» | Карточка в «T» | то же |
| Тема «T», вкладка словаря/списка | Строка в список (фокус на новую строку) | Карточка · Подтема |
| Тема «T», вкладка стиха | Карточка в «T» | Подтема |
| Профиль, Прогресс, Корзина, Справка | Домашнее задание | Карточка · Тема · Предмет |
| Слабые места | Карточка (в слабую тему) | Контрольная |

«Ещё в тему ›» раскрывает: Словарь · Даты · Формулы · Свой список · Стихотворение (только включённое). Так 6 пунктов нынешней вкладки «＋» (`TopicScreen.tsx:242-274`) не растягивают меню.

«**Быстрый вопрос**» = «Карточка» с компактной формой «вопрос — ответ» (остальное под «Ещё»). Если автор имел в виду вопрос нейросети по тексту — это пункт панели выделения, а не «＋» (Q4).

### 6.3 Как не конфликтует с существующими «＋»

| Существующее | Решение |
|---|---|
| «＋» в шапке «Предметы» и «папка+» (`Sidebar.tsx:508-513`) | Убираются; «Предмет» и «Папка» — в «＋ Создать» и в «⋯» заголовка «Знания». |
| «＋» в строках дерева: подтема, тема, предмет в папке (`:260,309,380`) | Убираются (в строке остаётся «⋯»). Те же действия — в «⋯» строки и в «＋» по контексту. |
| Строки контекстных меню «Новая тема», «Добавить подтему» (`:552,584,656`) | Остаются в «⋯» строки — вызывают то же действие из реестра. |
| «＋ Тема» на странице предмета (`SubjectScreen.tsx:68`), «＋ Предмет» в папке (`FolderScreen.tsx:35`), «＋ Карточка» (`TopicScreen.tsx:580`) | Не главные кнопки (главная — «Учить · N»). Остаются **только в пустом состоянии** как единственная главная кнопка и как кнопка внутри пустой вкладки. |
| «＋» у вкладок темы (`TopicScreen.tsx:242-274`) и кнопка «Правила» рядом (в 1.8 они уже налезали друг на друга) | «＋» убирается: словарь/список/стих — в «＋ Создать → Ещё в тему». «Правила» остаются как есть. |
| «＋» на карточке «Домашка» (`Homework.tsx:511`) | Убирается; «＋ → Домашнее задание» тем же окном `HomeworkForm`. |
| Строка быстрой записи на экране «Домашка» (`Homework.tsx:374`) | Остаётся — это главное действие того экрана; «＋» на этом экране ставит курсор в неё, а не открывает второе окно. |
| «＋ Вставить» в конспекте (формула, рисунок, таблица…), «＋ Строка/Столбец» таблицы, «＋ Вставить списком», «＋» строки списка, «＋ Новое правило» ×3 | **Остаются.** Это вставка/структура внутри объекта, а не создание сущности; подписаны текстом. «＋ Новое правило» вызывает действие «Правило» из реестра. |
| Ctrl+N («Новая тема», только в предмете) | Открывает меню «＋» (на экране темы/предмета первая строка — то, что делал Ctrl+N). |

**Правило:** *«＋» создаёт; «Вставить» вставляет; «Добавить» в строке списка — это внутрисписочная правка.* Две разные подписи не смешиваются.

## 7. Правила

### 7.1 Где живёт новая сущность

| Сущность | Дом | Показывается ещё |
|---|---|---|
| Папка, Предмет | Знания | Поиск, «＋» |
| Тема, Подтема | внутри предмета | «Скоро» (если есть контрольная), поиск |
| Конспект, Карточка | внутри темы (вкладки) | Слабые места, Поиск |
| Термин | список «Термины» темы; общие термины — Справочник предмета | Поиск |
| Правило | Справочник предмета | подсказка на слове в конспекте*, кнопка «Правила» в теме* |
| Словарь, Список, Стих | вкладка темы | шаг плана («расскажи стих»), Поиск |
| Домашнее задание | Учусь → Домашка | «Скоро», виджет, уведомление |
| **Контрольная (новая сущность)** | Учусь → Контрольные | «Скоро», дата в теме |
| Слабое место | **вычисляется**, не хранится | Учусь (топ-3), Знания → Слабые, подготовка к контрольной |
| Версия конспекта | у темы (⋯ → История) | — |
| Удалённое | Профиль → Корзина | тост «Вернуть» |
| Прогресс, итоги недели | Профиль → Мой прогресс | сводка на «Учусь» не показывается |
| Расписание уроков | Профиль → Расписание и напоминания | строка в «Скоро»*, шаг плана |
| Настройки, Возможности, Данные | Профиль | — |

**Правила определения дома для новых функций:**
- Создаёт и хранит ученик → Знания, внутри ближайшего объекта.
- Дело со сроком → Учусь («Скоро»).
- Действие/сеанс → кнопка на объекте + шаг плана, **не пункт меню**.
- Параметр → Профиль → Настройки; включает/выключает поверхность → Возможности.
- Документация → сайт; в приложении — подсказка в месте использования.
- Нельзя добавить пункт первого уровня, не убрав другой.

### 7.2 Что видно, когда функция выключена

1. **Нет входа:** ни пункта меню, ни кнопки, ни строки в «＋», ни в поиске, ни в справке, ни рекламы, ни «Включить» где-либо, кроме экрана «Возможности».
2. **Данные не удаляются** и возвращаются при включении; экспорт и резервная копия их содержат.
3. **Исключение — вкладка с данными** (словарь, стих в теме): вкладка остаётся (чтобы ученик не решил, что данные пропали), но создание новых, напоминания и «＋»-пункты исчезают. Правила, домашка, карта, итоги — прячутся целиком.
4. **Зависимости:** если B нужна A (ответ голосом на компьютере требует ИИ; напоминание об уроках требует расписания), пометка «нужен…» живёт только на плитке B в «Возможностях». В других местах B просто не видна.
5. Включение мгновенное; плитка в «Возможностях» одной строкой говорит, что появится и где (поле `where` уже есть, `featureList.ts`).
6. Состояние «функция есть, но нечего показать» (нет контрольных, нет правил) → пункт навигации скрыт, вход — только через «＋»/пустое состояние.

## 8. Сквозные правила экранов

### 8.1 Каркас страницы

```
Телефон:                               Компьютер:
[‹ Родитель]            [🔍]           Знания › Математика › Алгебра            ← крошки (нажимаются)
Заголовок объекта (1 строка)           Заголовок объекта           [Главная кнопка] [⋯]
подстрока (1 строка, серая)            подстрока (1 строка, серая)
[Главная кнопка ········] [⋯]          [вкладки ≤ 4]
[вкладки ≤ 3 в строку]                 содержимое
содержимое
```

1. **Шапка.** Верх: назад/крошки + поиск. Ниже — заголовок и **ровно одна главная кнопка** (`btn primary`), затем «⋯». Всё остальное — в «⋯».
2. **Главная кнопка** — глагол (+ число): «Учить · 12», «Готовиться», «Добавить первую тему». Для пустого объекта главная кнопка — создание (из реестра «＋»); для непустого — «Учить» в масштабе экрана (тема, предмет, папка, словарь, термины). Сегодня это непоследовательно: у предмета главная «＋ Тема», а «Учить весь предмет» в «⋯» (`SubjectScreen.tsx:67,73`); у папки наоборот (`FolderScreen.tsx:29-37`).
3. **Заголовок.** Название объекта; над ним серой строкой — крошки (компьютер) или родитель (телефон). Один ряд, обрезается. Название темы/предмета редактируется на месте (на телефоне — через «Переименовать» в «⋯», чтобы случайное касание не открывало клавиатуру: предположение, не проверено).
4. **Назад.** Всегда вверх по иерархии: тема → предмет → «Знания»; домашка → «Учусь». Android-«Назад»: закрыть окно/меню → выйти из полного экрана → вверх на уровень → на вкладке верхнего уровня — свернуть приложение. (Сейчас всегда «на Сегодня».) Для этого в `App.tsx` нужен стек маршрутов вместо одного `useState<Route>`.
5. **Вкладки внутри экрана** = разные виды **одного объекта** (Предмет: Темы / Справочник; Тема: Конспект / Карточки / пользовательские; Знания: Предметы / Слабые места / Карта; Контрольная: План / Слабые места). **Не** фильтры. ≤ 3 в строку на телефоне, ≤ 4 на компьютере (лишние — «Ещё»; решение «2+2 только если не помещаются» остаётся запасным). Две полосы вкладок/сегментов на одном уровне не ставить. Выбранная вкладка хранится в маршруте и запоминается по типу объекта.
6. **Фильтры и период** — маленький переключатель **рядом с блоками, на которые влияет**, а не в шапке экрана. Каждый независимый блок со своим горизонтом подписан сам («Итоги недели», «Нагрузка на 2 недели»).
7. **Пустое состояние** (`.empty`, 10 мест): **факт** («Тем пока нет») + **одна фраза зачем** («Тема — параграф или раздел учебника») + **одна главная кнопка** (создание из реестра «＋»). Без картинок и рекламы выключенных функций. После фильтра: «Ничего не нашлось» + «Сбросить».
8. **Действия над списками** (подтемы, предметы, карточки, термины, домашка, корзина, контрольные):
   - Нажатие на строку = открыть. В строке — не больше одного статуса (число к повторению) и одной полоски прогресса; кнопок нет (кроме галочки в домашке).
   - Меню строки: на компьютере «⋯» при наведении и ПКМ, на телефоне — долгое нажатие и «⋯». Состав: Открыть · Переименовать · Переместить · Выбрать · Удалить.
   - Выбор нескольких: «Выбрать» в меню → панель «Выбрано: N · Переместить · Удалить · Отмена» (сейчас — Ctrl/Shift или `DeleteManyDialog`, на телефоне долгое нажатие не проверено на устройстве).
   - Поиск в списке — при > 8 строк (сейчас разнобой: 8, 12, 8).
   - Порядок: разумный по умолчанию (по названию с числами / по сроку), смена — в «⋯» «Порядок». На телефоне перестановка — режим «Порядок» со стрелками, не перетаскиванием.
   - Удаление: **мягкое** (Корзина) + тост «Вернуть» 8–10 с. Диалог подтверждения — только для контейнеров (предмет, папка, тема с подтемами) и массового удаления; одиночную карточку/домашку удалять сразу + тост (сейчас три разных стиля: `ConfirmButton`, окно, сразу+тост).
9. **«⋯»:** ≤ 8 строк; порядок: работа с содержимым → поделиться/экспорт → управление → опасное (красное, последнее); группы через линию. Если строк больше — пункт группируется («Поделиться и экспорт ›»).
10. **Меню и «Ещё» на телефоне — всегда нижняя шторка**, не всплывающее меню у кнопки. Тогда меню физически не может выйти за край (баг 1 — этот класс). Окна на телефоне уже шторки (`styles.css:892-893`).
11. **Диалоги.** До 3 полей и одно решение — шторка/окно 520 px. Редактор содержимого (карточка, правило, формула, рисунок) — окно 620–980 на компьютере, на телефоне почти полный экран. Мастера (импорт, облако, синхронизация, файл изменений, обновление) — шаги, одна главная кнопка на шаге. Окно не открывает окно (кроме подтверждения). В окне нет вкладок.
12. **Тосты:** над нижней панелью на телефоне; с действием 8–10 с (сейчас 8 с, `App.tsx:398`), без действия 3,5 с.
13. **Названия.** Существительное — место, глагол — действие. Четыре глагола вместо шести: **«Учить»** (по расписанию, влияет на интервалы), **«Повторить всё»** (без влияния на расписание), **«Проверить себя»** (тест), **«Исправить»** (слабые места). «Начать/Готовиться/Разминка/Фокус» уходят в названия шагов плана.
14. **Телефон и компьютер.**
    - Режимов три: *телефон* (< 720 px) — нижняя панель, шторки, без hover; *сенсорный широкий* (указатель coarse, ≥ 720) — панель слева, но без hover-кнопок и без подсказок про мышь/клавиши; *компьютер* — панель слева, hover, ПКМ, клавиши.
    - На сенсорных экранах нет подсказок про клавиши и мышь (`kbd`, Ctrl+V, Esc, «>» в подсказке поиска, «правая кнопка»). Одна функция `layoutMode()` вместо пары `useMobile`/`touchUI`.
    - Действия, которые на компьютере появляются при наведении (⋯, ★, +), на сенсорных видны всегда либо в долгом нажатии.
    - Таблицы на телефоне — карточки (уже сделано); модальные окна — шторки; цели касания ≥ 44 px.
15. **Полноэкранные потоки** (повторение, тест, тренировка стиха, «Конспект на весь экран»): нет панелей, в левом верхнем углу «✕», по центру прогресс, справа счётчик/таймер; выход возвращает туда, откуда пришёл.

## 11. Зависимости, риски

**Зависимости (данные и код):**
- Д-1. Стек навигации вместо одного `useState<Route>` (`App.tsx:60`), единая точка «Назад» (`App.tsx:309-335`).
- Д-2. Сущность «Контрольная» (`exams?: Exam[]`, несколько тем, дата); миграция `Topic.examDate` → `Exam`; обратная совместимость (поле остаётся).
- Д-3. Корзина: мягкое удаление (нужны содержимое и `deletedAt`, не только метки `deleted`, `store.ts:333`), срок хранения (30 дней), согласование с синхронизацией (`sync.ts`, облако) и размером (картинки в конспектах).
- Д-4. История конспекта: хранение версий с учётом картинок (`data:`) — объём.
- Д-5. Реестр действий «＋» (`createActions`) — один источник для меню, поиска, пустых состояний.
- Д-6. Одна функция `layoutMode()` вместо `useMobile` + `touchUI`.
- Д-7. Правка e2e: 29 из 49 скриптов в `e2e/` ссылаются на «Меню / Статистика / Настройки / Возможности» (`m1.mjs` и др.).
- Д-8. Горячие клавиши: изменение умолчаний Ctrl+3.
- Д-9. Android-«Назад»; виджеты/уведомления (route-ключи сохраняются).

**Риски:**
- Р-1. Нижняя панель с «＋» — предположение о предпочтении автора; нужен макет (UI показывать до реализации).
- Р-2. Скрытие «Контрольных» до первой записи — прогрессивное раскрытие может смутить; альтернатива — показывать всегда.
- Р-3. «Профиль» без профиля (П-5).
- Р-4. Удаление сада/достижений необратимо для тех, кому они нравятся; можно оставить «Прогресс» без наград.
- Р-5. Слияние 3 вкладок «Справочника» в чипы — один лишний шаг для «Правил»; смягчение: «Правила» кнопкой в теме остаются.
- Р-6. Эффект «нижней шторки против выхода за край» — не проверен.
- Р-7. Перетаскивание на касании — не проверено на устройстве.
- Р-8. Планшет: режим «сенсорный широкий» не проверен.
