Это концепт для утверждения, не рабочее приложение: данные выдуманные, кнопки работают только там, где показан сценарий. Цвета и шрифты — настоящие, из Мнемы. Переключатели вверху показывают, что оформление остаётся настраиваемым и «ИИ не настроен» полностью прячет кнопки ИИ.
