Первая функция — «карточки из конспекта с ИИ» (потом «объясни мою ошибку»).
   - Что выяснено: у автора тариф GigaChat Freemium (до 03.10.2027: Lite 250 млн токенов, Pro 40 млн, Max 25 млн, Ultra ~50 млн; 1 одновременный запрос; модели в списке: GigaChat-3-Ultra, 2-Max, 2-Pro, 2, 3-Pro, 3-Lightning — названия в API могут отличаться).
