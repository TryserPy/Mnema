# Формулы в Мнеме

Формулы пишутся на языке LaTeX — так же, как в Obsidian и многих учебниках. В приложении есть визуальный редактор (кнопка «Вставить → Формула» в конспекте и «+ Формула» в карточке), так что синтаксис знать не обязательно.

## Как вставить

- **В строке текста:** `$E = mc^2$` — формула между двумя знаками доллара.
- **Отдельной строкой** (крупно, по центру):

```
$$
I = \frac{U}{R}
$$
```

- **В карточке** — так же: `$...$` в вопросе, ответе или объяснении.
- Чтобы изменить формулу в конспекте, нажми на неё.

## Математика

| Что | Как написать |
| --- | --- |
| Дробь | `$\frac{a}{b}$` |
| Степень | `$x^2 + x^{10}$` |
| Корень | `$\sqrt{x}, \quad \sqrt[3]{27} = 3$` |
| Нижний индекс | `$a_1, \; a_{n+1}$` |
| Умножение | `$a \cdot b$` |
| Сравнения | `$a \ne b, \; a \le b, \; a \ge b$` |
| Модуль | `$\lvert x - 3 \rvert$` (или просто `\|x - 3\|` — в таблице черту пришлось экранировать) |
| Плюс-минус | `$x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$` |
| Система уравнений | `$\begin{cases} x + y = 5 \\ x - y = 1 \end{cases}$` |
| Градусы и π | `$180^\circ = \pi$` |
| Синус, логарифм | `$\sin \alpha, \; \log_2 8 = 3$` |

## Физика

| Что | Как написать |
| --- | --- |
| Закон Ома | `$I = \frac{U}{R}$` |
| Вектор | `$\vec{F} = m\vec{a}$` |
| Изменение величины | `$v = \frac{\Delta s}{\Delta t}$` |
| Единицы измерения | `$v = 20\ \text{м/с}$` |
| Греческие буквы | `$\rho, \lambda, \omega, \eta$` |

## Химия

| Что | Как написать |
| --- | --- |
| Уравнение реакции | `$2H_2 + O_2 \rightarrow 2H_2O$` |
| Ион | `$SO_4^{2-}$` |
| Обратимая реакция | `$N_2 + 3H_2 \rightleftharpoons 2NH_3$` |

## Частые ошибки

- Забыт второй знак `$` — формула не станет красивой.
- Степень или индекс из нескольких символов берётся в фигурные скобки: `x^{10}`, а не `x^10`.
- Русский текст внутри формулы — через `\text{...}`: `v = 20\ \text{м/с}`.
