# Refrain 1.31 — задания потокам A–F (фаза 3)

Каждое задание самодостаточно: его можно отдать подагенту или открыть в новой сессии. Спецификация — артефакт «Refrain 1.31 — проект» (https://claude.ai/artifact/7w1CHSk4p311UAMpzYHAMN): разделы 1–9 и «Решено» — принятые решения, их не пересматривать.

## Общие правила для всех потоков

- Контракты (`docs/refrain-1.31/contracts.md`, `shared/refrain/*`, `shared/prompts/markup.ts`, `shared/prompts/tasks.ts`, `src/styleModel.ts`, `AiRequest`/`AiAnswer` в `src/store.ts`) **менять нельзя**. Нужна правка — остановись и верни вопрос ведущему с предложением.
- Меняй только файлы своего потока. Чужой файл нужен — верни вопрос, не правь. Новые файлы — только в своих папках/с префиксами, указанными ниже.
- Пиши как окружающий код: тот же стиль, русские комментарии только там, где неочевидно «почему». Без «заодно», без новых зависимостей без причины (каждую новую — назови в отчёте с причиной).
- Секреты, настоящие почты, ключи, ID — нигде (ни в коде, ни в тестах, ни в фикстурах). Примеры — `@example.com`.
- Приватность: конспекты, фото, ответы ИИ не уходят никуда, кроме выбранного ИИ; в логи не пишутся.
- Перед завершением: `npx tsc --noEmit`, `npx vitest run`, `npx vite build`, `npx vite build --mode web` в корне Mnema — всё зелёное. Не отключай и не ослабляй тесты. Коммить небольшими осмысленными коммитами в своей ветке (без `--no-verify`, без переписывания истории), **не пушь**.
- Отчёт: что сделано (файлы, коммиты), чем проверено (команды и итог, вывод при падении), что не сделано, вопросы к ведущему, новые зависимости.
- e2e: Playwright стоит глобально (`/usr/local/lib/node_modules_global`, `NODE_PATH` уже настроен), Chromium — `/opt/pw-browsers/chromium-1194/chrome-linux/chrome`. Образец — `e2e/overflow.mjs`.

## B. Выноски и разметка (раздел 7, редактор)

## E. Сайт (Mnema-site)

**Цель.** `admin/` — скрытая панель (как `stats/`: строгая CSP, `noindex`, токен только в памяти, все строки через `textContent`), `tg/` — мини-приложение Telegram (тот же API, вход по `initData`, сессия 15 минут в памяти), `privacy/` — что хранится (почта и цифры), сколько, как удалить аккаунт. Экраны: обзор (бюджет месяц/сутки, страницы, ученики сегодня, последний час), доступ (Выключен · Только я · Тестировщики · Все; «Все» и опасное — с PIN), тестировщики и приглашения, ученики (поиск, группа, блок/разблок), лимиты групп, бюджет, **тревоги** (непрочитанные, статус доставки), **блокировки** (снять, подтвердить ожидающий, «снять все» с PIN), **пороги детектора** (веса, пороги, сроки, сверка с OpenAI — с PIN), **журнал**, расход по дням и задачам, баги (В GitHub / Готово / Спам · блок), «Ключ заменён» (PIN) с инструкцией. Кнопки тревог из бота открывают `tg/#alert=<id>&do=<действие>&t=<цель>` — экран тревоги с этим действием (опасное — PIN).

**Контракт:** `shared/refrain/admin.ts` и `docs/refrain-1.31/contracts.md` в репозитории Mnema (только читать). Ошибки — `{ ok:false, error:{ code, message } }`. Адрес сервера — поле ввода с запасным значением, хранится только в `localStorage` (не секрет).
