## 1. API сервера

Адрес по умолчанию: `https://refrain-ai.<аккаунт>.workers.dev` (Brevo и `*.workers.dev`, пока не решено иначе). Все ответы — JSON.
Ошибка всегда выглядит так: `{ ok: false, error: { code, message, retryAfter?, until?, attemptsLeft?, quota?, devices? } }`.

### Вход

| Маршрут | Тело | Ответ |
| --- | --- | --- |
| `POST /v1/auth/pow` | `{ purpose: 'login' \| 'bug' }` | `{ challenge, difficulty, expiresAt }` |
| `POST /v1/auth/start` | `{ email, pow: { challenge, solution } }` | `{ ok: true }` для **любой** почты |
| `POST /v1/auth/verify` | `{ email, code, device: { publicKey, name, platform }, invite? }` | токены, `deviceId`, `quota`, `emailMasked` |
| `POST /v1/auth/refresh` (подписан) | `{ refreshToken }` | новая пара токенов |
| `POST /v1/auth/logout` (подписан) | — | `{ ok: true }` |

- Proof-of-work: `SHA-256(challenge + ':' + solution)` начинается с `difficulty` нулевых бит (по умолчанию 20 ≈ 1 с на телефоне с синхронной реализацией SHA-256). Задачка подписана сервером (HMAC), живёт 5 минут, решается один раз.
- Код: 6 цифр, в базе только HMAC-хэш, 10 минут, 5 попыток, потом 15 минут паузы (`code_locked`). Не больше 3 кодов в час на почту и 10 на IP. Одноразовые почтовые сервисы отклоняются (`email_rejected`, одинаково для существующих и новых почт).
- Ключ устройства: ECDSA P-256. Публичный ключ — SPKI в base64url. Секретный: Electron — `safeStorage`, Android — Android Keystore (не извлекается). Подпись — r‖s (64 байта, IEEE P1363) в base64url; Android отдаёт DER, приложение переводит.
- Токен доступа: 15 минут, подписан сервером (HMAC), содержит аккаунт, устройство и сессию. Токен обновления: 30 дней, в базе только хэш, меняется при каждом обновлении. Повтор старого токена обновления — `session_revoked` для всех сессий аккаунта и правило `refresh_reuse`.
- Устройств не больше, чем у группы (ученик 3). Лишнее — `device_limit` со списком устройств; код при этом не тратится, и повтор `verify` с `replaceDevice: <id>` отвязывает выбранное устройство.

### Подписанные запросы

Заголовки: `authorization: Bearer <access>`, `x-refrain-device`, `x-refrain-time` (мс), `x-refrain-nonce` (16 байт base64url), `x-refrain-signature`, `x-refrain-app: refrain/1.31.0 (windows|linux|android)`.
Подписывается строка:

```
REFRAIN-SIG-1
<METHOD>
<path без адреса сервера, с query>
<sha256 тела в hex; пустое тело — sha256 пустой строки>
<x-refrain-time>
<x-refrain-nonce>
<x-refrain-device>
```

Окно ±2 минуты, nonce помнится 5 минут на устройство. Любое несовпадение — `device_unknown` (без подробностей, какое именно).

| Маршрут | Тело | Ответ |
| --- | --- | --- |
| `POST /v1/task` | `{ task, image?, text?, subject?, topic?, page?, wishes? }` | `{ text, format, promptVersion, charged, quota }` |
| `GET /v1/me` | — | `{ emailMasked, quota, devices, access }` |
| `POST /v1/invite` | `{ code }` | `{ ok, quota }` |
| `DELETE /v1/devices/:id` | — | `{ ok }` |
| `DELETE /v1/account` | — | `{ ok }`: стираются почта, счётчики, устройства, сессии |
| `POST /v1/bug` (без входа, с PoW) | `BugReport` | `{ ok, id }` |

- `task` — одна из `TASKS`; рамки задачи — `TASK_SPECS` (есть ли фото, предел `text`, потолок ответа, рассуждение).
- Фото: JPEG/PNG/WebP, до 2 МБ после декодирования и до 2000 px по длинной стороне (сервер читает размер из заголовка файла). Приложение уменьшает до 1600 px.
- Лишние поля — `bad_request` (не отбрасываются молча: это сигнал детектора). Поля `system`, `prompt`, `messages`, `model`, `max_tokens`, `temperature`, `reasoning*`, `tools` — правило `own_prompt`.
- Один запрос на ученика одновременно; второй — `too_fast`.
- `quota` в каждом успешном ответе и в `limit_*`: `{ day: { used, limit }, month: { used, limit }, resetsAt, group }` в страницах (`limit: null` — без лимита).

### Коды ошибок

| Код | HTTP | Когда | Что показывает приложение |
| --- | --- | --- | --- |
| `limit_day` / `limit_month` | 429 | лимит страниц кончился | экран «На сегодня бесплатные страницы закончились» + «Без интернета / Свой ключ / Без ИИ» |
| `paused` | 503 | пауза: бюджет, аварийная, «Выключен» | «Refrain ИИ на паузе», переход к следующему по порядку |
| `access_closed` | 403 | закрытый тест | «Refrain ИИ сейчас в закрытом тесте» + поле приглашения |
| `blocked` | 403 | аккаунт заблокирован | «Доступ к Refrain ИИ приостановлен» + `until`, без причины срабатывания |
| `too_fast` | 429 | лимит в минуту, параллельный запрос, замедление | «Слишком часто, подожди N с» |
| `bad_request` / `payload_too_large` | 400 / 413 | нарушение контракта | ошибка приложения (это баг клиента) |
| `upstream` | 502 | OpenAI не ответил; страницы не списаны | «Сбой ИИ, попробуй ещё раз» |
| `token_expired` | 401 | истёк доступ | приложение само делает refresh |
| `device_unknown` / `session_revoked` | 401 | подпись, устройство, кража | войти заново |
| `device_limit` | 409 | устройств больше лимита | список для отвязки |
| `pow_invalid`, `email_rejected`, `code_invalid`, `code_locked`, `invite_invalid` | 400/429 | вход | текст у поля |

### Порядок поставщиков в приложении

В приложении запрос к ИИ — `AiRequest` (`src/store.ts`). Для Refrain ИИ к нему добавляется `refrain: { task, image?, text?, subject?, topic?, page? }` — те же данные без промта; «Свои указания» дописывает `aiRequest()` (поле `wishes`). **Запрос без `refrain` идёт мимо Refrain ИИ** (к своему ключу или без интернета): так моды и прочие свободные запросы не тратят ключ Refrain. Ответ `aiAsk` — `AiAnswer`: `via` (кто ответил), `quota`; при ошибке Refrain ИИ — `code` и `quota`.

`Refrain ИИ → свой ключ → без интернета` (настраивается). Следующий берётся при `limit_*`, `paused`, `access_closed`, `blocked`, `upstream`, нет сети. Ответы кэшируются на устройстве 7 дней по `sha256(фото или текст) + task + promptVersion`.

| `formula` | Формула от руки | 120 | 200 | none | LaTeX | да | — | 0,05 |

«Разворот» (2 страницы) — два запроса `textbook.*` по половинам, как сейчас.
Страница = $0,00065 (650 µ$): 2 000 токенов на вход и 900 на выход по $0,10 / $0,50 за миллион. Списывается настоящий расход по `usage`: `(вход − кэш) × 0,10 + кэш × 0,01 + выход × 0,50` за миллион. Перед запросом резервируется наибольшая стоимость (`maxCostMicro`), после — возвращается разница.
Модель — одна, `gpt-6-luna` (цены сверены с прайсом OpenAI: $0,10 вход, $0,01 кэш, $0,50 выход). Рассуждение задаём всегда явно: у модели по умолчанию `medium`.

| Группа | id | В день | В месяц | В минуту | Устройств |
| --- | --- | --- | --- | --- | --- |
| Ты | `owner` | без лимита | в общем бюджете | 20 | 5 |
| Тестировщик | `tester` | 100 | 1 500 | 10 | 3 |
| Новичок (первые 3 дня) | `newbie` | 10 | — | 4 | 2 |

Владелец определяется сервером по `OWNER_EMAIL` из секретов, не по настройке. Режимы: `off` (выключен для всех, и для владельца), `owner` (только я), `testers`, `all`. По умолчанию `testers`; переход на `all` — с PIN. Тестировщики — по почте (список в панели) и по приглашениям `RFN-XXXX-XXXX` (места, срок, группа; одноразово привязывается к почте).
Бюджет: $20 в месяц, в сутки — двойная средняя доля месяца. Тревоги на 50/80/100 %; на 100 % — пауза для всех, кроме владельца. Скачок: час втрое дороже среднего часа за неделю (и не меньше $0,20) → режим `testers` + тревога.

## 6. Детектор подозрительной активности

`shared/refrain/guard.ts`, реализация `server/src/guard/`.

**Субъекты:** аккаунт, устройство, IP, ASN. **Баллы** за срабатывание правила складываются у субъекта и затухают вдвое за 30 минут. IP получает полный вес только за анонимные события (неопознанный токен или устройство, вход, волна регистраций) и свои правила; за нарушения опознанного аккаунта — четверть (`ipShareKnown`), чтобы один ученик не заблокировал школьный NAT.
**Уровни:** ≥ 40 — уровень 1, ≥ 100 — уровень 2. Для тестировщиков порог ×2, и блок уровня 2 только после подтверждения; у владельца автоматически не блокируется ничего (только тревога).

| Правило | Баллы | Кому | Параметры |
| --- | --- | --- | --- |
| `sig_invalid` неверная подпись | 40 | устройство, IP | |
| `token_unknown` чужой/неизвестный токен | 15 | аккаунт, IP | |
| `device_unknown` | 15 | IP | |
| `nonce_replay` повтор nonce | 60 | аккаунт, устройство, IP | |
| `time_skew` время вне окна | 5 | устройство | |
| `refresh_reuse` старый токен обновления | 100, сразу уровень 2 | аккаунт, IP | |
| `impossible_travel` | 100 | аккаунт | > 900 км/ч и > 500 км (координаты Cloudflare) |
| `account_many_ips` | 30 | аккаунт | ≥ 6 IP за 30 мин |
| `ip_many_accounts` | 40 | IP | ≥ 8 аккаунтов/устройств за час |
| `unknown_task` | 25 | аккаунт, IP | |
| `extra_fields` | 15 | аккаунт, IP | |
| `oversize` | 15 | аккаунт, IP | |
| `own_prompt` свой промт | 45 | аккаунт, IP | |
| `parallel` | 8 | аккаунт | |
| `burn_rate` | 35 | аккаунт | час > 4× нормы группы и > 5× своей, не меньше 15 страниц |
| `machine_rhythm` | 30 | аккаунт, IP | ≥ 12 запросов, разброс интервалов < 8 % |
| `expensive_only` | 15 | аккаунт | ≥ 12 запросов, ≥ 90 % — самые дорогие задачи |
| `ua_missing` | 10 | IP | |
| `app_version_unknown` | 20 | аккаунт, IP | версии нет в списке выпусков (конфиг) |
| `signup_wave_ip` | 40 | IP | ≥ 5 новых аккаунтов с IP за час |

**Почему такие числа.** Одна случайность не должна блокировать: сбитые часы (`time_skew` 5), одна лишняя кнопка (`parallel` 8), одно лишнее поле (15) не дотягивают даже до уровня 1. Уровень 1 (замедление, обратимо само через 15 минут) — это два-три явных признака подряд. Уровень 2 — либо однозначная кража (`refresh_reuse`, `impossible_travel`), либо сумма нескольких признаков за полчаса: например, повтор nonce + неверная подпись (60 + 40). При полураспаде 30 минут ученик, у которого раз в день что-то идёт не так, никогда не набирает порог. Пороги `account_many_ips` (6 за 30 мин) и `ip_many_accounts` (8 за час) выше обычной жизни: телефон между Wi-Fi и мобильной сетью — 2–3 IP, школьный NAT — несколько учеников с одного IP, поэтому такие правила сами по себе дают только уровень 1.

**Реакции:**
- уровень 1 — лимит в минуту ÷ 3 на 15 минут для субъекта, ответ `too_fast`;
- уровень 2 — блок аккаунта на 24 часа (`blocked`), отзыв токенов, отвязка устройства, блок IP на 60 минут / ASN на 30 минут (ASN — только если на уровне 2 одновременно несколько IP одного ASN);
- уровень 3 — режим `owner` («Только я», запоминается прежний режим для «Вернуть режим»): если за 15 минут уровень 2 у 10 и больше аккаунтов, или подозрение на утечку ключа.
Каждая реакция — запись в журнал (`JournalEntry`: причина, правила, баллы, до/после) и, для уровней 2–3, тревога. Разблокировка — только из панели или бота. Все реакции обратимы, кроме смены ключа OpenAI.

**Утечка ключа.** Раз в 10 минут сервер берёт из OpenAI Usage API (`GET /v1/organization/usage/completions`, `bucket_width=1m`, фильтр `project_ids`, `group_by=model`) токены проекта за окно 60 минут, закончившееся 15 минут назад (данные приходят с опозданием), считает по ним стоимость и сравнивает со своим учётом за то же окно. Утечка, если: у OpenAI больше на 25 % **и** на $0,50; или у нас 0 запросов, а у OpenAI больше $0,10; или в данных есть модель, которую сервер не вызывает. Для этого нужен отдельный админ-ключ организации (`OPENAI_ADMIN_KEY`), рабочий ключ проекта эти данные не читает. Реакция — уровень 3 и критическая тревога с инструкцией: создать новый ключ в проекте → `wrangler secret put OPENAI_API_KEY` → отозвать старый → в панели «Ключ заменён» и снять паузу. Отозвать ключ сам сервер не может и прав на это не хранит.

## 7. Тревоги (раздел 8 + защита)

| Тревога | Уровень | Когда | Что сервер делает сам |
| --- | --- | --- | --- |
| Бюджет 50 / 80 / 100 % | ⚠️ (100 % — 🚨) | за месяц | на 100 % — пауза для всех, кроме тебя |
| Скачок расхода | ⚠️ | за час втрое больше среднего за неделю | режим → «Тестировщики» |
| Жадный ученик | ⚠️ | аккаунт потратил больше 5 % дневного бюджета | ничего; кнопка «Заблокировать» |
| Волна регистраций | ⚠️ | больше 30 новых за час или больше 5 с одного IP | лимит «Новичка» временно 0 |
| Сбои OpenAI | ⚠️ | больше 20 % ошибок за 10 минут | ничего; кнопка «Пауза» |
| Вход в панель, неверный PIN | info / ⚠️, 5 PIN — 🚨 | всегда | после 5 ошибок панель закрыта на час |
| 🚨 Подозрение на утечку ключа | 🚨 | расход OpenAI заметно выше нашего учёта, либо расход при нуле запросов | аварийная пауза Refrain ИИ для всех, кроме тебя |
| Подделка/повтор запроса | ⚠️ | неверная подпись, повтор nonce, старый токен обновления | отзыв токенов, отвязка устройства, при повторе блок аккаунта |
| Аккаунт с нескольких мест | ⚠️ | «невозможное перемещение» или много IP за короткое время | уровень 2: блок аккаунта и тревога |
| Выход за рамки контракта | ⚠️ | неизвестная задача, лишние поля, своя инструкция вместо задачи | уровень 1, при повторе уровень 2 |
| Блок IP / ASN | ⚠️ | много аккаунтов или ошибок с одного адреса | временный блок, срок в конфиге |
| 🚨 Аварийная пауза | 🚨 | уровень 3 | режим «Только я» |

Доставка: Telegram сразу; при неудаче повтор через 30 с, 2 мин, 10 мин; после 3 неудач — письмо на `OWNER_EMAIL`. Непрочитанные хранятся в D1 и видны в панели. Одинаковые некритичные тревоги за 10 минут склеиваются в одно сообщение со счётчиком «ещё 14 за 10 минут». Критические (🚨) идут со звуком и всегда отдельно, остальные тихо (`disable_notification`). В тексте нет секретов, полных почт (`g***@mail.ru`), полных IP (последний октет скрыт) и содержимого запросов. Кнопки: «Заблокировать», «Разблокировать», «Пауза», «Вернуть режим», «Открыть панель» — открывают мини-приложение, опасные действия там с PIN.

## 8. API панели

`shared/refrain/admin.ts`: вход через `initData` Telegram (HMAC от токена бота, свежесть 5 минут, ID из секретов) или код на почту владельца + PIN; токен 15 минут, только в памяти страницы; опасные действия с заголовком `x-refrain-pin`. Бот: вебхук с секретным заголовком, команды `/status` и `/pause`.

## Расхождения с документом и дополнения

1. **Поле `text` в `/v1/task`.** В документе тело `{ task, image?, subject?, topic?, page?, wishes? }`, но задачи «Свести параграф», «Карточки», «Объяснить иначе», «Стиль» работают с текстом без фото. Добавлено поле `text` с пределом на задачу.
2. **Аварийная пауза = режим «Только я».** Задача говорит «Выключен для всех, кроме тебя», а документ — что «Выключен» останавливает и владельца. Уровень 3 переключает на `owner`; `off` остаётся ручной аварийной кнопкой.
3. **Лишние поля не отбрасываются молча**, как сказано в разделе 6 документа («Лишние поля отбрасываются»), а дают `bad_request` и сигнал `extra_fields` — так требует задача про детектор. Клиент Refrain их не шлёт.
4. **Proof-of-work на `/v1/bug`** — та же задачка с `purpose: 'bug'`.
5. Ссылки на код из документа совпадают: `design.css:92`, `StyleGallery.tsx:257` (`mod.where`), `mdImport.ts:303–305` (303 — «Запомните»-рамки, 304 — остальные выноски в цитату, 305 — блочные ссылки), `ModsSettings.tsx:36` (`BASE_TILES`), фильтр «Виды/Каталог» — `ModsSettings.tsx:166–167`.
