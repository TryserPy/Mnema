# Мнема

Офлайн-приложение для школьников: параграф учебника → конспект → карточки → повторения по расписанию.
Цель — **запоминать больше, тратя меньше времени**: Мнема встраивает в учёбу то, что по исследованиям
действительно работает, — вспоминание без подсказки и повторение с перерывами.

Работает на **Windows** и **Android**. Всё хранится на устройстве, аккаунт не нужен, рекламы нет.

## Скачать

Последняя версия — на странице [выпусков](https://github.com/TryserPy/Mnema/releases/latest):

- **Windows** — `Mnema-Setup-<версия>.exe`: запусти и следуй установщику.
- **Android** — `Mnema-<версия>-Android.apk`: открой на телефоне и разреши установку из этого источника.

Дальше Мнема обновляется сама: раз в день проверяет выпуски и предлагает поставить новую версию
(«Настройки → О Мнеме → Обновления»). Карточки, предметы и настройки при обновлении сохраняются.

## Для разработки

```bash
npm ci
npm run dev            # в браузере: http://localhost:5173
npx tsc --noEmit       # проверка типов
npx vitest run         # модульные тесты
npm run build          # сборка в dist/
```

- Код интерфейса — `src/` (TypeScript + React + Vite), Windows — `electron/`, Android — `android/`
  (своя обёртка WebView без Gradle; сборка `bash android/build.sh` после `npm run build`).
- Подробное описание проекта — [`docs/PROJECT.md`](docs/PROJECT.md), заметки для Claude — [`CLAUDE.md`](CLAUDE.md),
  агенты-помощники — [`.claude/agents/`](.claude/agents), сценарии проверки интерфейса — [`e2e/`](e2e).

### Как выпустить новую версию

1. Поднять версию в `package.json` и `src/update.ts`, дописать «Новое в …» в `src/screens/Settings.tsx`
   и раздел в [`CHANGELOG.md`](CHANGELOG.md) (этот текст увидят пользователи).
2. Запушить тег `vX.Y.Z` — GitHub Actions (`.github/workflows/release.yml`) проверит код, соберёт APK
   и установщик Windows и опубликует выпуск. Приложения сами найдут его.

Для подписи APK нужен секрет репозитория **`ANDROID_KEYSTORE_B64`** — ключ `mnema-release.jks` в base64
(«Settings → Secrets and variables → Actions»). Ключ один на все версии: с другим ключом обновление не встанет
поверх. В репозиторий ключ не кладётся.

## История версий

## Что есть в 1.0
- Предметы и темы, конспект в редакторе без разметки (хранится в Markdown)
- Формулы: визуальный редактор (MathLive), `$…$` и `$$…$$` в тексте — см. [docs/formulas.md](docs/formulas.md)
- Рисунки в конспекте (хранятся как SVG прямо в Markdown, можно дорисовать)
- Карточки: вопрос — ответ, в обе стороны, с пропуском, с вводом ответа; «В карточку» из выделения
- Повторение по FSRS, простой режим с двумя кнопками
- Экран «Возможности»: трудные карточки, пробная контрольная, фокус-режим, расписание уроков, уверенность перед ответом, советы, импорт из Obsidian
- «Закрой и перескажи», обмен темами файлом `.mnema`, резервные копии

## Новое в 1.1 — «ИИ и руки»
- ИИ-помощник: Claude, Gemini (ключ API) или модель на компьютере через LM Studio. Ключи шифруются (safeStorage), запросы идут из главного процесса
- Формула от руки: нарисовать на холсте → ИИ переводит в LaTeX → правка в редакторе
- «Объясни иначе» на трудной карточке, объяснение можно сохранить в «почему»
- Ответ от руки при повторении, сравнение с правильным ответом
- Карта знаний: предметы → темы → жирные понятия; общие понятия связывают темы, слабые места подсвечены
- Значок у часов: число карточек, напоминание, мини-повторение 5 карточек по Ctrl+Alt+M, автозапуск
- Импорт из Anki: .apkg (старый и новый формат), .colpkg, .anki2/.anki21, текстовый экспорт; картинки, формулы, пропуски c1/c2, перенос прогресса через FSRS

- Таблицы в конспекте (`@tiptap/extension-table`, Markdown), темы по названию с учётом чисел (`topicOrder`), выбор нескольких и `deleteMany`

- Команда агентов и хранитель контекста (`.claude/agents`, `.claude/context/CONTEXT.md`)

## 1.7 — нейросеть, телефон и обновления
- Файл изменений (`src/changes.ts`): нейросеть пишет JSON — Мнема показывает план и применяет (создать и поменять что угодно, «Вернуть»); «Выгрузить для нейросети»; готовая инструкция
- Обновления из выпусков GitHub `TryserPy/Mnema`: на Android APK скачивается и ставится через PackageInstaller (`android/.../Updater.java`), сборка выпусков — GitHub Actions
- Телефон: пункты Мнемы в меню выделения Android (`MnemaWebView.java`), «Важное» снизу, меню внутри экрана, подписи инструментов, переключатели в два ряда, щипок в графе, поглаживание растений
- Значок под тему (`Icons.java`, activity-alias), виджеты «Повторить», «Домашка», «Уроки» (`Widgets.java`)
- Мост `MnemaAndroid` принимает вызовы только с ключом главной страницы

## 1.6.4 — стихи наизусть

- Вкладка «Стихотворение» в теме (кнопка «+»). Стих делится на части (по 2/4 строки или по строфам).
- Учить: каждая часть — прочитать → половина слов → первые буквы → по памяти → вместе с предыдущими (метод нарастающих частей и исчезающих подсказок).
- Проверка вслух: сверка со словами текста — пропуски, замены, запинки (пауза или повтор), точность в процентах. На Windows — через ИИ-помощника.
- Без голоса: открыть текст и отметить строки с ошибками.
- «С любого места», подсветка трудных строк, повтор выученного стиха через 1, 3, 7… дней на экране «Сегодня».

## 1.6.3 — меньше лишнего в конспекте

- Панель выделения (жирный, маркер, в карточку, ссылка, правило) открывается правой кнопкой мыши; на телефоне — как раньше, сама.
- Жирный, курсив и маркер не продолжаются, если просто поставить курсор после выделенного слова.
- Вкладка «Термины» у предмета: общие термины предмета и термины всех тем с разбивкой по темам, учить всё или по теме.
- Правило открывается окошком (текст, слова-подсказки, изменить), страница правила — только если в нём формулы или рисунки.

## 1.6.2 — ссылки и словари
- Ссылки на темы, правила и термины (`src/links.ts`, `src/components/Links.tsx`): в Markdown — `[текст](mnema://card/<id>)` / `mnema://topic/<id>`; выбор по выделению (панель или правая кнопка), подсказка при наведении, Ctrl+щелчок — переход; в Obsidian — `[[Тема|текст]]`
- Словари: ширина столбцов (перетаскивание границы, `StudyList.widths`), «просто термин» без ответа (не учится), клетки новой строки переносят текст так же, как готовые
- Порядок вкладок темы (`Topic.tabOrder`, `src/tabs.ts`): перетаскивание, «Левее/Правее» в настройках списка
- Меню «+» у вкладок не вылезает за окно

## 1.6.1 — рисунки и мелочи
- Холст: фон (как у конспекта — прозрачный, тёмные чернила светлеют в тёмной теме; белый, бумага, клетка, линейка, точки, тёмный), свои цвета ручки и маркера, весь экран, размер в конспекте (30–100 %) и предпросмотр. Рисунок «как у конспекта» встраивается в страницу как SVG (`inlineDrawing`)

- Домашка: фото по Ctrl+V

## Новое в 1.6 — «Меньше времени, больше толку»
- План до контрольной (`examPlan`/`examBoost` в `src/srs.ts`): новые карточки темы раскладываются поровну до дня перед контрольной (сверх дневного лимита), в последние 2 дня — «освежить заранее» то, что по кривой забывания FSRS к контрольной будет помниться хуже 90 %. План — на «Сегодня» и в теме
- Перед уроками: «Подготовиться к завтра» (карточки завтрашних предметов), утренняя «Разминка» — 5 самых подзабытых карточек сегодняшних уроков без изменения расписания (`warmupCards`), вечернее уведомление «Завтра: …»
- «Почему?» после верного ответа (самообъяснение), объяснение сохраняется в карточку; возможность `why`
- Карточки из всего конспекта одной кнопкой (`NoteToCards`)
- Фото к домашке (сжатие до 1400 px, просмотр)
- Виджет Android (`MnemaWidget.java`): карточки на сегодня (посчитаны на неделю вперёд), домашка на завтра, «Повторить 5»
- Обновление из выпусков GitHub: на компьютере electron-updater (`electron/updater.cjs`) — скачать и перезапустить; на телефоне — ссылка на APK из выпуска

## Новое в 1.5 — «Домашка»
- Новый внешний вид по умолчанию («Современный», тема «Воздух»); прежний — стиль «Классический». Смена темы одним плавным переходом (View Transitions), без рывков
- Настройки по разделам: слева список, справа один раздел, поиск по настройкам; на узком экране — список → раздел. «Возможности» — плитки по группам с подробностями в окне
- Домашка (`src/homework.ts`, `src/components/Homework.tsx`): быстрая запись в одну строку, срок «к следующему уроку» по расписанию, напоминания накануне; уведомления Windows (`electron/notify.cjs`) и Android (`Reminders.java`, AlarmManager)
- Уроки на «Сегодня» (сегодня и завтра) и окно «Расписание уроков» на неделю
- Папки предметов, 24 цвета + свой, значки предметов (выбор по кнопке)

- Сад знаний: 8 стадий роста, небо по времени суток, растение можно открыть, полить (повторить) и погладить; «подрос!» после роста

- Поиск и команды по Ctrl+P
- Вкладки темы без прокрутки (лишние — в «Ещё»), тонкие полосы прокрутки в цвет темы, проверка вылезающего текста на всех экранах

## Команды
- `npm install`
- `npm run dev` — интерфейс в браузере (данные в localStorage)
- `npm test` — тесты логики
- `npm run build` — сборка интерфейса
- `npx electron .` — запуск приложения после сборки
- `npm run dist` — установщик Windows (на Linux нужен wine с 32-битной частью)
- `bash android/build.sh` — APK после `npm run build` (нужны aapt2, javac, dx, zipalign, apksigner и android.jar API 23+). Ключ подписи — `android/mnema-release.jks`: храни его, обновления APK подписываются только им

## Структура
- `electron/` — окно, файл данных в `%APPDATA%\Mnema`, резервные копии, доступ к папке Obsidian
- `src/srs.ts` — очередь, FSRS, расписание уроков, трудные карточки
- `src/store.ts` — данные и сохранение
- `src/testgen.ts` — пробная контрольная
- `src/obsidian.ts` — перевод заметок Obsidian
- `src/anki.ts` — чтение колод Anki (sql.js, fflate, fzstd), `test-fixtures/` — тестовые колоды
- `electron/ai.cjs` — запросы к ИИ, `electron/tray.cjs` — трей, напоминания, мини-режим
- `src/components/NoteEditor.tsx` — редактор конспекта (TipTap), `FormulaEditor.tsx`, `Drawing.tsx`
- `src/screens/` — экраны
